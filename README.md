# Webetu Auto Meals

تطبيق Android لجدولة تذكيرات حجز الوجبات الجامعية على منصة Webetu.

## الرفع
1. ارفع **كل الملفات الموجودة في هذا المجلد** إلى جذر المستودع (بدون مجلدات).
2. أنشئ المجلد `.github/workflows/` وضع فيه ملف `blank.yml` (هذا هو الاستثناء الوحيد، لأن GitHub يشترط هذا المسار).

## البناء
- كل `push` يبني APK تلقائيًا. افتح تبويب **Actions**، ثم آخر عملية، ثم حمّل `WebetuAutoMeals-debug-APK` من **Artifacts**.
- خطوة `restore-layout.sh` في سير العمل تعيد ترتيب الملفات إلى بنية مشروع Android أثناء البناء.

## ملاحظات
- التطبيق **لا يسجل الدخول** إلى Webetu ولا يحجز نيابةً عنك. في موعد المحاولة يرسل تنبيهًا لإتمام الحجز بنفسك.
- زر **إيقاف طارئ** في لوحة التحكم يوقف كل الجدولة فورًا.
