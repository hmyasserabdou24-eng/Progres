# مشروع Webetu Auto Meals — تطبيق Android للحجز التلقائي للوجبات الجامعية

## 🚀 كيفية تشغيل البناء على GitHub تلقائيًا:
1. ارفع جميع الملفات الموجودة في هذا المجلد مباشرة إلى مستودعك الجديد في GitHub.
2. توجه إلى ملف `.github/workflows/blank.yml` أو أنشئ سير عمل باسم `build.yml` وضع فيه محتوى ملف `build.yml` المرفق.
3. سيبدأ البناء تلقائيًا عبر خادم Ubuntu مجاني وينشئ لك ملف `WebetuAutoMeals-debug-APK` في قسم Artifacts للتنزيل على هاتفك فورًا.
